# Exercise 3 — Agent + Tool

An LLM can reason over information it receives, but it cannot automatically read a local file or access an external system.

In this exercise, we give the agent a **custom file-reading tool**.

## Your task

Run the provided program and observe when the agent decides to use the tool.

Then change the question in `agent_with_tool.py` and run it again.

Think about what the tool gives the agent that the LLM does not have by itself.
