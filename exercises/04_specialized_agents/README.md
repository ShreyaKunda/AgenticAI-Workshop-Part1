# Exercise 4 — Specialized Agents

Now we use two agents with different responsibilities.

The first agent researches a topic. The second agent receives that output and summarizes it.

This example intentionally does **not** use a Crew. The agents are called manually so you can see how output can be passed from one agent to another.
