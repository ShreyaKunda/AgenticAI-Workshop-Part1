# Exercise 5 — Create a Crew

In this exercise, we move from manually connecting agents to a formal CrewAI workflow.

The Crew contains three specialized agents:

1. Researcher
2. Threat Analyst
3. Security Advisor

The tasks are connected using context so later tasks can use earlier findings.

## Your task

Complete the TODO sections in `crew.py` and run:

```bash
python crew.py
```

Pay attention to the order of the tasks and how information moves through the Crew.
